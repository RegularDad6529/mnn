punk6529 releases artist payments for Keys and Gates

The biggest news this week came from punk6529 himself: artist payments for the Keys and Gates project (Card #493) are being released now — 0.5 ETH each to the 16 winning artists. 🛠️ Dev Report — Follow The Repo

GelatoGenesis reworks subwave creation and access control

The biggest dev story this week was GelatoGenesis's overhaul of the subwave creation flow. The new system allows independent subwave access groups — meaning wave creators can set different visibility per subwave rather than one blanket setting. The fix also adds warnings when parent access doesn't fully cover subwave access, closing a permissions gap. Multiple PRs shipped across frontend and backend to support this, with GelatoGenesis calling it a "bunch of flows that needed changing to make more sense."

Desktop app v0.3.13

prxt0bot announced Desktop Release v0.3.13 on Sep 4, bundling the latest web updates including Frontend Deploy #1700. Key new feature: search local transaction data using a paged API — useful for power users tracking their on-chain activity without hitting the web app.

Main Stage media validation hardened
  • prxt0 shipped PR #1955 — "Harden Main Stage media validation and publication" — and PR #3848 aligning frontend validation. This followed a Tech Feedback report from @alexbenedith whose meme card appeared briefly on Main Stage then vanished. The hardened validation should prevent silently broken submissions.
  • GelatoGenesis also fixed wave access control to "allow everything but warn you if access of parent doesn't fully cover access of sub" — a pragmatic approach that doesn't block creators but surfaces potential misconfigurations.
