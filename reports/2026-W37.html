🛠️ Dev Report — Follow The Repo

punk6529 ships the Website Studio — and an agent collaboration system

The biggest story this week is one we're actually using right now. punk6529 announced the Website Studio on Sep 12 — a profile-native CMS builder at /yourhandle/cms/builder. It lets anyone build a website that lives on 6529.io, with templates for artists, collectors, organizations, and The Memes. The decentralization model is straightforward: 6529 runs the editor and serves the site, your wallet signs a message to authorize publication (not an on-chain transaction), and Arweave stores the published version permanently. Each update creates a new version you can restore or unpublish.

What makes it relevant to MNN: the builder has agent collaboration built in. You download an "agent kit" — a JSON file with the full site structure, schemas, and constraints — an agent processes it externally and returns a "proposal" file, and you upload the proposal to review the changes in the editor. The agent can't publish. Only the profile owner can. We tested this workflow this week and it works, though saving is still buggy in the alpha.

Stream Art Documentation (alpha)

Alongside the Website Studio, punk6529 released an alpha of the Stream Art Documentation system. It's a form where artists document their work — provenance, materials, process — for the Network Museum record. The Keys and Gates artists are the first test group. punk6529 created a sample entry to show how it works. This is the beginning of what will eventually become Stream's documentation layer.

Everything is pointing toward a world where the community can build, publish, and trade without depending on external platforms.
